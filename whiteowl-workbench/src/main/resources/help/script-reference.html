Overview

Scripts are written in Groovy and execute within a sandboxed DSL environment. Each script type has its own base class that provides bar data, indicator functions, and type-specific methods. Scripts are compiled once and cached in memory for the session.

Scripts are plain .groovy files managed in the Scripts panel. Press Ctrl+S in the script editor to save and recompile instantly.

Common API

The following variables and functions are available in all script types (Indicators, Screeners, Rankers, and Strategies).

Bar Data Variables

These are pre-bound float[] arrays (or long[] for volume/timestamps) indexed from 0 (oldest) to barCount - 1 (newest).

VariableTypeDescription
openfloat[]Opening price of each bar
highfloat[]Highest price of each bar
lowfloat[]Lowest price of each bar
closefloat[]Closing price of each bar
volumelong[]Volume traded for each bar
timestampslong[]Epoch milliseconds for each bar
barCountintTotal number of bars available

User Inputs

Declare configurable parameters that appear as editable settings in the UI. If no inputs are declared, no settings dialog is shown.

SignatureDescription
input(name, defaultValue)Declares a numeric input with a default value
input(name, default, min, max)Adds min/max bounds
input(name, default, min, max, step)Adds step increment for UI spinner
def period = input("Period", 20, 5, 200)
def multiplier = input("Multiplier", 2.0, 0.5, 5.0, 0.5)
input() returns a Number. Use .intValue() or .doubleValue() when passing to functions that require a specific type.

Indicators

Indicator scripts compute a numeric series that is plotted on the chart. The script must return a float[] (or double[]) array of the same length as the bar data.

Display Mode

Control where the indicator is rendered by calling displayMode at the top of your script:

ModeDescription
"subchart"Default. Rendered in its own pane below the price chart with an auto-scaled Y-axis. Best for oscillators and values not in the price range (e.g., RSI, Bollinger Width).
"overlay"Drawn directly on the candlestick chart using the price Y-axis. Best for moving averages, bands, and other price-relative indicators.
"volume"Drawn on the volume pane. Use for volume-based indicators.

Example: Simple Moving Average (overlay)

displayMode "overlay"

def period = input("Period", 20, 5, 200)
return sma(close, period.intValue())

Example: RSI (sub-chart)

displayMode "subchart"

def period = input("Period", 14, 2, 50)
return rsi(close, period.intValue())

Example: Bollinger Bandwidth (sub-chart)

def period = input("Period", 20, 5, 100)
def mult = input("Multiplier", 2.0, 0.5, 5.0, 0.5)
def p = period.intValue()
def m = mult.doubleValue()

def mid = sma(close, p)
def width = new float[barCount]
for (int i = p - 1; i < barCount; i++) {
    float sum = 0
    for (int j = i - p + 1; j <= i; j++) {
        float diff = close[j] - mid[i]
        sum += diff * diff
    }
    float stddev = (float) Math.sqrt(sum / p)
    width[i] = (2 * m * stddev) / mid[i]
}
return width

Example: EMA Crossover Signal (overlay)

displayMode "overlay"

def fastPeriod = input("Fast", 9, 2, 50)
def slowPeriod = input("Slow", 21, 5, 200)
return ema(close, fastPeriod.intValue())

Example: Volume SMA (volume overlay)

displayMode "volume"

def period = input("Period", 20, 5, 100)
def volFloat = new float[barCount]
for (int i = 0; i < barCount; i++) volFloat[i] = volume[i]
return sma(volFloat, period.intValue())

Screeners

Screener scripts filter stocks by returning a boolean. Return true if the stock passes the screen, false otherwise. The script is evaluated once per stock using its most recent bar data.

Example: Price Above 50 SMA

def period = input("Period", 50, 5, 200)
def ma = sma(close, period.intValue())
def last = barCount - 1
return close[last] > ma[last]

Example: RSI Oversold

def period = input("RSI Period", 14, 2, 50)
def threshold = input("Threshold", 30, 10, 50)
def rsiValues = rsi(close, period.intValue())
def last = barCount - 1
return rsiValues[last] < threshold.doubleValue()

Example: Golden Cross

def fast = sma(close, 50)
def slow = sma(close, 200)
def cross = crossover(fast, slow)
// true if golden cross happened in the last 5 bars
for (int i = barCount - 5; i < barCount; i++) {
    if (i >= 0 && cross[i]) return true
}
return false

Example: High Volume Breakout

def lookback = input("Lookback", 20, 5, 100)
def volMult = input("Volume Multiplier", 2.0, 1.0, 5.0, 0.5)
def lb = lookback.intValue()
def last = barCount - 1
if (barCount < lb + 1) return false

def hi = highest(high, lb)
long avgVol = 0
for (int i = last - lb; i < last; i++) avgVol += volume[i]
avgVol /= lb

return close[last] > hi[last - 1] && volume[last] > avgVol * volMult.doubleValue()

Rankers

Ranker scripts compute a numeric score for each stock. Stocks are then sorted by this score. The script must return a Number (e.g., float, double).

Rankers support input() parameters just like Indicators and Screeners. Declare configurable parameters the same way using input(name, defaultValue).

Example: Rate of Change Ranker

def last = barCount - 1
if (barCount < 21) return 0
return (close[last] - close[last - 20]) / close[last - 20] * 100

Example: RSI Ranker

def rsiValues = rsi(close, 14)
def last = barCount - 1
return rsiValues[last]

Example: Relative Volume Ranker

def last = barCount - 1
if (barCount < 21) return 0
long avgVol = 0
for (int i = last - 20; i < last; i++) avgVol += volume[i]
avgVol /= 20
if (avgVol == 0) return 0
return (double) volume[last] / avgVol

Example: Momentum Score Ranker

def last = barCount - 1
if (barCount < 201) return 0

def roc20  = (close[last] - close[last - 20])  / close[last - 20]  * 100
def roc60  = (close[last] - close[last - 60])  / close[last - 60]  * 100
def roc120 = (close[last] - close[last - 120]) / close[last - 120] * 100
def roc200 = (close[last] - close[last - 200]) / close[last - 200] * 100

return roc20 * 0.4 + roc60 * 0.3 + roc120 * 0.2 + roc200 * 0.1

Trading Strategies

Strategy scripts generate entry and exit signals for backtesting. The script iterates over bars and emits signals using dedicated functions. Strategies can also reference other indicator scripts by name.

Signal Functions

FunctionDescription
longEntry(barIndex)Enter a long position at bar
longEntry(barIndex, timing, price)Enter long with fill control
longExit(barIndex)Exit a long position at bar
longExit(barIndex, timing, price)Exit long with fill control
shortEntry(barIndex)Enter a short position at bar
shortEntry(barIndex, timing, price)Enter short with fill control
shortExit(barIndex)Exit a short position at bar
shortExit(barIndex, timing, price)Exit short with fill control

Fill Timing

ValueDescription
CURRENT_BARFill on the same bar the signal is generated
NEXT_BARDefault. Fill on the next bar after the signal

Fill Price

ValueDescription
OPENDefault. Fill at the bar's open price
HIGHFill at the bar's high price
LOWFill at the bar's low price
CLOSEFill at the bar's close price
TYPICAL_PRICEFill at (high + low + close) / 3

Referencing Indicator Scripts

Use indicator("ScriptName") to compute a custom indicator script and get its output as a float[]. The indicator must exist in the Scripts panel.

def bollingerWidth = indicator("Bollinger_Width")

Example: SMA Crossover Strategy

def fastPeriod = input("Fast", 10, 2, 50)
def slowPeriod = input("Slow", 30, 10, 200)

def fast = sma(close, fastPeriod.intValue())
def slow = sma(close, slowPeriod.intValue())
def bullCross = crossover(fast, slow)
def bearCross = crossunder(fast, slow)

for (int i = 0; i < barCount; i++) {
    if (bullCross[i]) longEntry(i)
    if (bearCross[i]) longExit(i)
}

Example: RSI Mean Reversion Strategy

def rsiPeriod = input("RSI Period", 14, 2, 50)
def oversold = input("Oversold", 30, 10, 45)
def overbought = input("Overbought", 70, 55, 90)

def rsiValues = rsi(close, rsiPeriod.intValue())

for (int i = 1; i < barCount; i++) {
    if (rsiValues[i - 1] < oversold.doubleValue() &&
        rsiValues[i] >= oversold.doubleValue()) {
        longEntry(i, NEXT_BAR, OPEN)
    }
    if (rsiValues[i] > overbought.doubleValue()) {
        longExit(i, NEXT_BAR, OPEN)
    }
}

Example: Breakout Strategy with ATR Stop

def breakoutPeriod = input("Breakout Period", 20, 5, 100)
def atrPeriod = input("ATR Period", 14, 5, 50)
def atrMult = input("ATR Multiplier", 2.0, 1.0, 5.0, 0.5)

def hi = highest(high, breakoutPeriod.intValue())
def atrValues = atr(atrPeriod.intValue())
def mult = atrMult.doubleValue()

boolean inTrade = false
float stopLoss = 0

for (int i = 1; i < barCount; i++) {
    if (!inTrade && close[i] > hi[i - 1]) {
        longEntry(i)
        stopLoss = close[i] - (float)(atrValues[i] * mult)
        inTrade = true
    } else if (inTrade && low[i] < stopLoss) {
        longExit(i)
        inTrade = false
    }
}

Tips & Patterns

Accessing the Last Bar

def last = barCount - 1
def currentClose = close[last]

Guard Against Insufficient Data

if (barCount < 50) return false  // screener
if (barCount < 50) return 0      // ranker

Computing Custom Values Per Bar

def result = new float[barCount]
for (int i = 0; i < barCount; i++) {
    result[i] = (high[i] - low[i]) / close[i] * 100  // bar range %
}
return result

Using MACD Components

def result = macd(close, 12, 26, 9)
def macdLine  = result[0]  // MACD line
def signalLine = result[1]  // Signal line
def histogram  = result[2]  // Histogram

Percentage Change

def last = barCount - 1
def pctChange = (close[last] - close[last - 1]) / close[last - 1] * 100

Combining Multiple Conditions (Screener)

def last = barCount - 1
def ma50 = sma(close, 50)
def ma200 = sma(close, 200)
def rsiValues = rsi(close, 14)

def aboveMa50 = close[last] > ma50[last]
def ma50AboveMa200 = ma50[last] > ma200[last]
def rsiHealthy = rsiValues[last] > 40 && rsiValues[last] < 70

return aboveMa50 && ma50AboveMa200 && rsiHealthy
