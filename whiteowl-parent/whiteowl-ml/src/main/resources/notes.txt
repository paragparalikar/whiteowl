Candidates : PCR, Long Buildup, Short Buildup, Long unwinding, Short unwinding, volatility skew, India VIX, IV, 
% change in total OI, % change in Call OI, % change in Put OI, highest OI on strikes as levels
Random Forest Classification

4. Use Random Forest as meta classifier trained on output of previous three models and actual value.


To automate technical analysis : 

1. Resolve levels using gap extremities, tops and bottoms (using ZigZagIndicator), volume profile(in case of indices use number of bars)

2. Use Clustering algorithms to merge above values into actual support/resistence levels.

3. Train a model on three bar ohlcv values that resulted in reversal and not. 

Combination of three bar reversal probability at support/resistance level should give good indication of reversal.
