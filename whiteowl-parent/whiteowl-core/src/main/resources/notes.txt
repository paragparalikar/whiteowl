Using Random forest for price prediction - tricks

1. Use Random Forest with hyperparameter optimization to predict open, high, low, close prices 
2. Using cross-validation, get and persist the error in prediction for each bar in step 1.
3. Train and optimize a separate Random Forest model to forecast this error
4. Use model constructed in step 3 to predicate value at next stage
5. Repeat step 2 to 4 for N number of times, where N is a hyperparameter to be optimized

Create a RF model to predict success/failure class for above model. 
If |prediction - actual| is more than predefined percentage, it is considered a failure.
Use method described in steps 1 to 5 to train this lateral decision making RF to drop any failure predications.
