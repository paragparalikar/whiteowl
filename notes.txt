2. Select one configuration from each group with highest Spearman Rank correlation with percentage returns.
3. Collect all most optimal configurations from each filter.
4. select the  filter with highest Spearman Rank correlation with percentage returns.
5. Incrementally select / rank all other filters by ratio of their own correlation with percentage returns to their correction with already selected feature set.

Intraday Ranking Strategy:
1. Generate a feature file with symbol as rows and date as column. This data file should specify percentage change from open to (close - open) / open

2. Cluster all these symbols using DBSCAN algorithm. We want dense clusters, thus keep sigma a little lower where we get maximum silhouette score.
To achieve this we will have to perfrom clustering on multiple sigma values and vsualize the curve with silhouette score.
3. From each cluster, select top N symbols for below metric: avg(abs(C-O) x sqrt(CxV))
Here we are trying to select symbols with highest movement on average at the same time has good liquidity.
4. Use ListNet to rank these symbols using below features:
 (O-C1)/C1

** Position Sizing **
Predict the returns of long and short sides separately for each day. To achieve this:
1. Calculate historic percentage returns we would have had, if we followed ListNet's ranking and allocated same amount for each position on both long and short side.
2. Apply Kelly Criteria to these historical returns to generate target variables. ie What fraction of portfolio value we should have assigned to long and short side.
No allocation for 0 or negative returns.
3. Use XGBoost to predict the fractional allocation.
